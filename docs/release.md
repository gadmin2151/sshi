SSHI 0.2.0 добавляет графический клиент на GTK для Linux и приложение на SwiftUI для Apple Silicon. Командная строка и интерфейс на этих системах работают с общей библиотекой подключений.

- Именованные профили, история и переносимая резервная копия JSON для Linux, Windows и macOS.
- Портативный Windows-клиент с импортом, экспортом и командой `proxy` для OpenSSH.
- Проверка выбранного relay при повторном использовании туннеля и проверка Endpoint ID перед выдачей приглашения.
- Пакеты Debian для amd64, arm64 и armhf, RPM для x86_64 и aarch64, Windows x64 EXE и установщик macOS arm64.

При обновлении с 0.1.4 перезапустите службу получателя от её владельца. Резервная копия переносит профили и историю. Данные входа и приватная идентичность остаются на устройстве.

Инструкции по установке и первому подключению доступны в [README](https://github.com/gadmin2151/sshi/blob/v0.2.0/README.md). Контрольные суммы загрузок находятся в `SHA256SUMS`.
